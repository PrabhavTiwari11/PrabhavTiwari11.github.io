# Prabhav Tiwari — Portfolio

Modern portfolio rebuilt from the current resume and the old HTML portfolio.

## Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- Lucide React

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Before deployment
1. Replace `https://example.com` in `app/layout.tsx` with the real domain.
2. Add a real `public/resume.pdf` if you want PDF instead of DOCX.
3. Replace project GitHub links with the exact repositories for each project.
4. Run `npm run build`.
5. Deploy to Vercel/another Next.js host.
